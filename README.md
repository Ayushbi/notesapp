#Notes App
## Tech Stack

- Flutter
- Dart
- Firebase
- Cloud Firestore
- Firebase Cloud Messaging (FCM)
- Firebase Cloud Functions
- JavaScript

## Features

- Create notes
- Read notes
- Delete notes
- Store notes in Cloud Firestore
- Store FCM device tokens
- Cloud Functions for notifications *(prototype / learning purpose)*

## status
- This project is currently under development and is mainly a learning project.
